# 球了个球 V0.3.1

原创 Canvas 2D 圆形弹球小游戏。Vite + TypeScript，无游戏引擎、第三方素材或付费资源。V0.1 的 4203 方块、鼠标/触摸控制、暂停、重开与再次发射均保留。

## 运行与检查

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev -- --port 5173
npm run typecheck
npm test
npm run build
```

开发地址：http://localhost:5173 。生产资源输出至 dist/。

浏览器回归检查（先启动服务器，系统需安装 Chromium）：

```sh
npm run test:browser
# 可通过 CHROMIUM_PATH 指定 Chromium 路径，BASE_URL 指定服务器地址。
```

## 操作

- 鼠标横移或手指拖动控制挡板；点击“开始游戏”发射。
- 暂停后点击顶部“继续”。页面隐藏自动暂停，物理、掉落、粒子、连击与强化计时一起停止。
- 所有球逃逸后回到准备状态，可再次发射；剩余方块保留。重开清空强化、掉落、粒子和连击，恢复全部方块与一个球。
- 每消除 14 个方块掉落一个道具，三倍与加宽交替出现。移动挡板接住道具。
- “×3”：按照拾取时的有效球数量添加两倍新球，最多 100 球。新球方向分散，位置分离并约束在圆内；附近有方块时减少生成偏移。
- “加宽”：挡板扩大至 1.8 倍，持续 5 秒；重复拾取刷新为 5 秒。界面显示剩余时间，加宽时及时限制挡板位置。
- 静音按钮关闭所有程序化音效；再次点击开启。浏览器首次点击开始或触摸后激活音频，音频不可用时仍能玩游戏。
- “百球压力测试”重开并启动 100 个球。球正常逃逸，页面模式不自动补球。

## 物理与性能

- 1/120 秒固定步长，每个子步移动距离最多 2 个逻辑像素；最多进行三次接触解算，随后重新约束圆边界。空间网格限定碰撞候选格；法线反射和位置修正避免墙内重复反射。
- 球的回收数组原地压缩，死亡对象复用；生成时仅按拾取前的存活球数计算三倍，避免指数循环生成。游戏中的球之间不进行互相碰撞。
- 方块销毁先原子修改存活标记，再触发粒子/掉落事件；多个球碰撞同一格只计数一次。
- 离屏方块画布在首次绘制、重开或尺寸改变时重建，其余时候只清除被销毁的格子。
- 粒子和闪光使用循环对象池，满池覆盖最旧效果。音效按类别限频，声部结束后断开节点，避免百球音效过载。
- 显示器 30/60/144 Hz 使用同一固定物理结果；单帧最多累计 0.1 秒，长时间后台停顿不补算。

## 实测结果

2026-11-09：类型检查通过，24 项 Vitest 测试通过，生产构建通过。

Chromium 自动回归通过：实际掉落拾取触发三球及加宽、暂停冻结球/强化/效果/掉落、重开恢复单球和零计数、首次点击激活 AudioContext、静音增益降为零、手机 390×844 无横向溢出、真实触摸拖动挡板。页面脚本异常数 0。

性能测量：无头 Chromium，桌面视口 1440×1200，初始 4203 个方块，两个阶段各 5 秒：

| 场景 | 同时球数 | 平均帧率 | 帧间隔 P95 | 单次物理更新均值 / P95 |
| --- | --- | --- | --- | --- |
| 正常百球模式 | 95～100 | 60.10 FPS | 16.8 ms | 0.053 / 0.200 ms |
| 测试脚本自动补球 | 始终 100 | 60.11 FPS | 16.8 ms | 0.047 / 0.200 ms |

正常百球模式渲染提交均值 0.189ms、P95 0.300ms，消除 952 块；持续百球场景消除 973 块。补球只在自动化测试内发生。测量包含计时包装器，渲染提交时间不等于 GPU 总耗时；帧率取决于运行设备。这些数据不能代表手机真机或长时间运行。

原始测试数据保存在 work/v02-browser-results.json，截图保存在 work/v02-powers.png、work/v02-mobile.png。work/ 为忽略的本地测试产物。

V0.2 更新了原有回归测试：死亡球现在被立即回收，刷新率比较改为比较有效球集合；原高速测试曾将球放在实心方块区内部，现改为从合法底部空白区撞击方块，并新增孤立薄方块多入射点测试。

## 已知限制与后续

手机真机 60 FPS、长时间百球运行和音色舒适度仍需人工/真机验证；音频自动化仅验证 API 状态和静音增益，不代表听感验收。当前仍为单关卡，无存档或排行榜。后续可加入多关卡、难度曲线与音量调节。

## V0.3：圆外水平挡板（历史记录）

挡板中心 y=898，顶边 y=892，圆底 y=852，视觉间隔 40 逻辑像素。正常挡板中心范围 x=96～704；加宽后按实际宽度限制在竞技场左右边界之间。保持水平直线造型与固定高度，无旋转或圆周运动。

球通过底部开口后标记为圆外状态，继续模拟；圆外球碰到闭合圆弧的外侧时向外反弹，不吸附进圆内。接住后向出口方向反弹，撞击位置仍会改变反弹方向。球整体离开 Canvas 才回收。发射时按当前位置重新瞄准底部出口，掉落道具也能到达圆外挡板。三倍生成保留父球的圆内/外状态。

“开始游戏”“暂停/继续”“重新开始”位于页面第一行，PC/手机均水平排列。32 项单元测试通过；增加 8 项圆外挡板测试。生产包浏览器回归验证完整出圆接球再入圆、漏接重发、顶部按钮、左右平移及触摸。运行 `BASE_URL=http://127.0.0.1:4173 node tests/browser-v03.mjs` 可重现截图。
