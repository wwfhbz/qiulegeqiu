# V1.6 满屏关卡与每关渐变配色

## 为什么改

V1.5 把第3～12关砖数降到1500～2500，但仍用原来9像素的细网格，所以砖块只在场地中央排成一小块圆盘，和铺满场地的前两关观感割裂。前两关道具也仍然偏多。

|---|---|---|---|---|
| 1 | 22/20 | 600 | 89% | 预分配20%：96个X3 + 24个加宽 |
| 2 | 16/14 | 1200 | 92% | 预分配12%：86个X3 + 58个加宽 |
| 3 | 15/13 | 1320 | 90% | 每14块随机一个（新手组合） |

| 6 | 13/11 | 1800 | 91% | |
| 7 | 12/10 | 2000 | 86% | |
| 8 | 12/10 | 2100 | 91% | |

| 11 | 11/9 | 2480 | 90% | |

机关、球速、出口、挡板、计分和生命不变。配置位于 `src/Levels.ts` 的 `LATER_LAYOUTS`，道具配额位于 `src/BrickPowerRules.ts`。

## 配色

- `shared/VisualTheme.ts` 的 `levelPalettes`：每关上/中/下三个锚点颜色，插值成六条色带；1～6关各有一套，7～12关复用。
- 色带按固定96逻辑像素高度划分，与砖块大小无关，每关都能看到完整渐变；颜色只取真实行号，与列、种子和已消除砖块无关（沿用此前“稳定色带”要求）。
- 碎片颜色跟随所在砖块；机关、道具颜色不变。

## 兼容与发布

- 1.5.0 冻结为 `V15_RULES_VERSION`/`V15_LEVELS`，1.3.0 同样保留，服务端照常验证；全球榜只排 1.6.0，旧成绩在个人历史中分别显示为“V1.5赛季记录”“V1.3赛季记录”。
- `deploy/leaderboard-contract.mjs` 登记了 1.5→1.6 和 1.3→1.6（若 1.5 尚未上线）两条桥接。
- 发布：合并后在服务器运行 `cd /home/ubuntu/qiulegeqiu && git pull --ff-only && bash deploy/update.sh`，脚本会自动先 `--api-only` 再正式发布。
