# 无尽规则 1.5（endless-1.5.0-3l-sink-v6）

## 变化
- **丢命后压线计时清零**：所有弹球掉落（`lost` 事件）时，`EndlessField.pressure` 归零。旧版会把剩余计时带到下一次发射，可能 1 秒内连丢两命。
- **压线补偿闪电计分**：客户端在发放压线补偿前就进入 running 状态，闪电击碎的砖块记录为 `hit` 事件并得分。服务端验证器本来就按这种顺序校验（bonus 事件之后同一 tick 的 hit），旧客户端因缺少这些 hit 而被拒。

其余数值（掉落、技能、下沉速度）与 1.4 完全相同。

## 兼容
- 1.0–1.4 冻结保留，旧成绩照常验证；无尽榜仍按 `all-endless-versions` 统一排名。
- 先部署服务端，再发布网页和小游戏：旧服务端不认识 1.5，会让新客户端本局以单机进行。

## 相关上限
- 单局事件上限 `MAX_CHALLENGE_EVENTS = 200000`（客户端与服务端共用）；90% 时游戏内提醒。
- 每会话每小时可创建挑战 120 个。
