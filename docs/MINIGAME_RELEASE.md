# 微信小游戏 V1.0 上线前清单

本项目交付可构建的Canvas小游戏客户端、兼容后端扩展及自动化测试，不等于已具备运营或审核资格。不接广告、支付，不读取微信好友关系或精准位置。

## 必须由运营方完成

- 注册正确类型的小游戏主体与AppID，确认主体和类目适用性；在服务器私密配置真实AppSecret。
- 微信后台配置request合法域名`https://ball.gmgnclaw.com`（填写域名，不带/api路径），核对HTTPS证书及相关备案；服务端另需允许到官方api.weixin.qq.com的HTTPS出站。
- 在另行审批后发布兼容后端；不改其他游戏Nginx，不开放API公网端口，不重建排行榜SQLite。
- 在开发者工具和iOS/Android真机验证导入/启动、wx.login真实换码、会话重返、后台/前台、触屏、安全区、100球性能和好友分享。游客AppID和测试换码器都不能替代正式认证。
- 检查完整十关、五种道具、机关、五命续关、结束提交/跳过、跨端榜单和网页账号安全绑定。
- 完善隐私保护指引：实际运营主体/联系方式、信息处理目的、保存期限、用户更正/注销删除流程、未成年人及第三方处理说明。代码中的政策是开发模板，正式信息缺失前不得宣称审核就绪。
- 在微信后台完成所需隐私接口申报，依据实际工具/基础库验证隐私授权流程；不以“不收集好友信息”代替完整披露。
- 核实游戏内容、原创素材和音效权属，准备著作权材料；当前Canvas与分享卡为代码原创，工具依赖按各自开源许可使用。
- 按实际主体、发行地区、类目及运营方式核实小程序/小游戏备案、ICP相关手续、网络游戏出版审批/版号、出版及运营主体授权、实名防沉迷、适龄提示等适用要求。不接广告/支付**不构成自动豁免结论**。

- [国家新闻出版署国产网络游戏作品审批](https://www.nppa.gov.cn/bsfw/xksx/cbfxl/wlcbfwspsx/202210/t20221013_600725.html)：游戏出版审批和资质材料应按适用流程核实。

本环境能够检索工信部和国家新闻出版署资料，但微信官方文档直连未能打开，因此不声称已逐条核实微信后台当前的具体审核条目、游客模式限制或基础库版本。上线前应由运营主体在真实微信后台确认；不能把其他平台的规则代替微信规则。
