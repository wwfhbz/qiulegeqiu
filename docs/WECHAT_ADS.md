# 微信广告与增长功能（V2.7）

## 开通后怎么启用
1. 小程序后台 → 流量主 → 开通（累计用户达到平台门槛后可申请）。
2. 广告管理 → 新建广告位，分别创建：激励视频、插屏、Banner（结算页底部）。
3. 把三个广告位 ID（`adunit-` 开头，是公开标识，不是密钥）填进 `wechat-game/src/AdConfig.ts`：
   ```ts
   export const AD_UNITS={rewarded:'adunit-xxxx',interstitial:'adunit-yyyy',banner:'adunit-zzzz'};
   ```
4. `npm run build:wechat`，在微信开发者工具导入 `wechat-game/dist` 上传。
某个 ID 留空，对应入口就自动隐藏，其余照常。

## 放置原则（参考已验证的做法：激励视频是主要收入）
| 类型 | 出现时机 | 不出现的时候 |
|---|---|---|
| 激励视频·复活 | 生命耗尽时（每局最多 2 次）；无尽模式复活时一次清掉最底部 20 行（规则 1.7）；闯关模式复活后下一球随机送 ×3球/闪电/火球/穿透 之一（规则 1.10） | 有命时、单局已复活 2 次 |
| 激励视频·下一球 +3 | 丢一条命后、下一次发射前（每局最多 3 次） | 关卡开局、首次发射 |
| 激励视频·跳过本关 | 闯关暂停菜单（每局最多 2 次，第 12 关不能跳；无通关/生命奖励） | 无尽模式、最后一关、已跳 2 次 |
| 激励视频·开局补给（V2.20） | 无尽模式第一次发射前："▶ 看视频开局：+3 球 · 30 秒护盾"（护盾期间压线不计时），每局 1 次 | 闯关、已发射过、已知服务器未支持 |
| 激励视频·压线救援（V2.20） | 无尽模式砖墙压线超过 5 秒："救命！看视频清底部 5 行"（播放时暂停），每局 1 次 | 未压线、护盾期间、已用过 |
| 激励视频·碎片翻倍（V2.20） | 结算页/闯关结束卡："▶ 看视频 本局碎片×2"，本局（本关）获得过碎片时出现，只能翻倍一次 | 本局没获得碎片 → 改为每日视频碎片 |
| 激励视频·碎片 | 皮肤页、结算页、闯关结束卡"▶ 看视频领 3 碎片"，每天最多 8 次；碎片每款 10 片永久兑换皮肤 | 当天已领满 |
| 激励视频·试用 | 星数已开放但碎片不够时"▶ 试用 XX 2小时"，所有皮肤合计每天 1 次（V2.20 起；之前一生 3 次） | 当天已试用 |
| 皮肤门槛（星星，不消耗） | 流星 3、霓虹光剑 6、爱心 9、烈焰燃烧 12、花瓣 15、黄金荣耀 18 星开放兑换 | — |
| 插屏 | 主动按暂停键打开菜单 | 前 3 局；距离上次不足 3 分钟；"再来一局"永不弹 |
| Banner | 结算页底部 | 游戏中、开始页 |

奖励只在视频完整看完（`isEnded`）后发放；中途关闭或无填充时只提示，不影响游戏。

## 排行榜与校验
- 新日志事件：`skip`（闯关跳关，最多 2 次，服务端能力 `ad-skip-v1`）；`revive`（生命耗尽后，最多 2 次）和 `boost`（丢命后的那次发射同一 tick，最多 3 次，+3 球）。闯关与无尽的服务端回放都会校验次数和时机，伪造会被拒绝。
- 服务器在 `/api/health` 的 `challengeFeatures` 中公布 `ad-revive-boost-v1`。联网对局只有服务器支持该能力时才提供复活/加球，避免旧服务器拒绝整局；单机对局不受限制。
- 开局补给 `supply` 与压线救援 `rescue`（无尽 1.8，服务端能力 `ad-supply-rescue-v1`）：补给只能在整局第一次发射的同一 tick，+3 球并开 30 秒护盾；救援要求压线已超过 5 秒，清底部 5 行；各每局 1 次，服务端回放校验。联网时只有服务器声明该能力才显示补给；若玩家先领了补给再选联网而服务器未更新，本局自动按单机进行。
- 复活与加球不改变计分规则，闯关 1.9、无尽 1.6 的规则版本不变。

## 音乐与设置
背景音乐由 `src/Audio.ts` 实时合成（每帧调度，不依赖定时器和音乐文件）。微信设置页：背景音乐、音效、震动、彗星拖尾，均保存在本机存储。
