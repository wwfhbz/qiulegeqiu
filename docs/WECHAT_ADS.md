# 微信广告与增长功能（V2.7）

## 开通后怎么启用
1. 小程序后台 → 流量主 → 开通（累计用户达到平台门槛后可申请）。
2. 广告管理 → 新建广告位，分别创建：激励视频、插屏、Banner（结算页底部）。
3. 把三个广告位 ID（`adunit-` 开头，是公开标识，不是密钥）填进 `wechat-game/src/AdConfig.ts`：
   ```ts
   export const AD_UNITS={rewarded:'adunit-xxxx',interstitial:'adunit-yyyy',banner:'adunit-zzzz'};
   ```
4. `npm run build:wechat`，在微信开发者工具导入 `wechat-game/dist` 上传。
某个 ID 留空，对应入口就自动隐藏，其余照常。

## 放置原则（参考已验证的做法：激励视频是主要收入）
| 类型 | 出现时机 | 不出现的时候 |
|---|---|---|
| 激励视频·复活 | 生命耗尽时（每局最多 2 次）；无尽模式复活时一次清掉最底部 20 行（规则 1.7）；闯关模式复活后下一球随机送 ×3球/闪电/火球/穿透 之一（规则 1.10） | 有命时、单局已复活 2 次 |
| 激励视频·下一球 +3 | 丢一条命后、下一次发射前（每局最多 3 次） | 关卡开局、首次发射 |
| 激励视频·小球拖尾 | 设置页：彗星、爱心、彩虹各看一次永久解锁 | 已解锁后 |
| 激励视频·挡板皮肤 | 设置 → 皮肤：霓虹光剑、星河冰晶、黄金荣耀各看一次永久解锁 | 已解锁后 |
| 插屏 | 主动打开菜单 | 前 3 局；距离上次不足 3 分钟；"再来一局"永不弹 |
| Banner | 结算页底部 | 游戏中、开始页 |

奖励只在视频完整看完（`isEnded`）后发放；中途关闭或无填充时只提示，不影响游戏。

## 排行榜与校验
- 新日志事件：`revive`（生命耗尽后，最多 2 次）和 `boost`（丢命后的那次发射同一 tick，最多 3 次，+3 球）。闯关与无尽的服务端回放都会校验次数和时机，伪造会被拒绝。
- 服务器在 `/api/health` 的 `challengeFeatures` 中公布 `ad-revive-boost-v1`。联网对局只有服务器支持该能力时才提供复活/加球，避免旧服务器拒绝整局；单机对局不受限制。
- 复活与加球不改变计分规则，闯关 1.9、无尽 1.6 的规则版本不变。

## 音乐与设置
背景音乐由 `src/Audio.ts` 实时合成（每帧调度，不依赖定时器和音乐文件）。微信设置页：背景音乐、音效、震动、彗星拖尾，均保存在本机存储。
