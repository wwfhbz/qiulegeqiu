## 基线与范围

保留半宽53的窄出口、圆心(400,492)、半径360、圆外水平挡板中心y=1018、宽112/厚12、圆底到挡板顶边160、最多100球、三命、原积分/连击、道具、音效、中央按钮与底部双按钮。

仓库实际仍是此前确认的三关，未发现十关/障碍物配置。本次没有新增或删除关卡，没有声称验证不存在的十关系统；ArcadeRules、LevelManager、ScoreSystem 和 Blocks 的规则均未修改。

## 唯一死亡条件

WorldGeometry.ts 集中派生外框和漏球线位置：

| 几何 | 数值 / 公式 |
| --- | --- |
| 左侧围挡中心线 | 24 = 圆左端40 − sideGap16 |
| 右侧围挡中心线 | 776 = 圆右端760 + sideGap16 |
| 上侧围挡中心线 | 112 = 圆顶132 − topGap20 |
| 玩家挡板下边缘 | 1024 = 1018 + 12/2 |
| 唯一漏球线 | 1072 = 挡板下边缘1024 + deathGap48 |
| Canvas | 800×1120，仅用于显示，不是球的死亡区域 |

只有 `ball.y - ball.radius > FRAME.deathY` 才返回死亡。减去球半径表示整个球已越过；与线相切时仍存活。判定不读取 Canvas 边界、CSS 尺寸、设备像素比或球的 x 坐标。

- 圆内、出圆、圆外、左右或上围挡碰撞、挡板反弹：都不死亡。
- 从挡板旁边漏过，但整球尚未超过1072：继续模拟。
- 整球越线：标为死亡，本固定物理步中结束其运动，然后统一回收。
- 外框底部只有低对比暖色虚线“漏球线”，不参与碰撞，没有阻止漏球的底部墙。

## 物理顺序

继续采用1/120秒固定步长，子步移动不超过2逻辑像素，速度上限760。

每个子步：

1. 移动球。
2. 处理圆弧/出口端盖、外围框架碰撞。
3. 处理玩家水平挡板和最多三次方块接触。
4. 再校正圆弧与外围框架位置，避免接触修正造成交叠。
5. 最后才调用唯一死亡谓词，决定该球是否离场。

原圆弧几何、内外法线和整球出入圆标记保持。外围框架由左右、上方三条实线组成；增加上围挡避免球从圆外侧上飞后离开视野而长期不可见。没有底部实线。框架的描边宽、中心线与圆角下端盖同样用于物理。侧面间隙16、顶部20大于球与描边的双倍接触半径10.4，避免圆弧与外框之间出现夹死通道。

## 移除入口审计

| 原入口 | V0.5.1处理 |
| --- | --- |
| boundary 内 Canvas 的左、右、底边越界判死 | 全部删除；boundary只做圆弧碰撞 |
| 外围框架 | 只反射与位置修正，不移除球 |
| Physics.update | 所有接触完成后，仅通过 isBallInDeathZone 标记游戏死亡 |
| recycleDead | 每个固定物理步结束后统一原地压缩存活数组，回收已标记的死亡对象 |
| triple | 新生球校正圆弧和外框位置，不因Canvas坐标被丢弃，下一物理步仍使用同一死亡区域 |
| resetRound | 重开、切关和扣命后清理的行政性对象释放；不计为游戏死亡，也不自行扣生命 |
| Game.update | 只在运行中、回合已发射且全部球死亡时扣一命 |

## 多球与整轮结算

Game.start从ready发射时设置roundActive。暂停/恢复不创建新回合。只有运行状态才进入物理和结算分支：

- 有任意存活球：不扣命。
- 所有球死亡且roundActive为真：先关闭回合标记，再扣一次生命。
- 即使同帧100球死亡、同一显示帧有多个物理子步，也只结算一次。
- 剩余生命大于0，清空道具和强化，保留方块与总分，生成1颗准备球，显示“▶ 继续挑战”。等待时不重复扣命。
- 生命为0进入Game Over，不再发射。
- 通关检查始终排在漏球结算之前；最后一球死亡与最后一块消除同帧时，仍按原生命奖励通关。
- 暂停同时冻结运动、碰撞、死亡回收、连击、道具及生命结算。

## 测试证据

类型检查、95项单元测试、生产构建通过。保留原75项测试（将原“Canvas边界死亡”用例改为验证该错误行为已经移除），新增20项覆盖完整单球/多球场景、暂停、同帧通关、760高速碰撞和外框几何。

生产包浏览器使用真实固定步长运行：先为球设置一次可复现的初始位置与速度，观察其出圆、碰左框、碰玩家挡板、重新入圆并击碎方块，全程存活且生命为3。随后设置漏接场景，记录球在挡板下仍存活，直到整球越线才移除。多球场景观察10→9→1不扣命，最后一颗越线后才由3命变2命。

PC和手机3倍DPR像素采样均确认左/右/上围挡存在、底部没有实体围挡；真实触摸、中央恢复、暂停阻止死亡和底部双按钮通过。浏览器报告无脚本异常。

原有中央交互、烟测、窄出口、水平位置、完整街机和道具/百球浏览器回归均通过。独立5秒持续百球桌面Chromium测试约60.16 FPS，仅代表当前环境；手机真机帧率和音效听感仍需设备验收。
