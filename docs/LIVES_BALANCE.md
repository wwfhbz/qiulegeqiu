# V0.6.1 五命续玩、生命同步与道具平衡

## 基线与问题定位

以GitHub main `7b428f38c42211c2f091180923582c507f97880c`为基线。已核对现有源码、测试、配置和文档。正式配置实际仍为三关，没有第5关或十关障碍配置；本次不新增关卡或重设计UI。

现有生命回合标记及resetRound已能保留关卡、消块与积分，本次保留该结构并增加验证。旧代码的onChange仅在动画帧绘制末尾调用，直接update完成扣命后不会立即通知界面；新增回归要求update返回前HUD已与内部状态一致。不能仅凭源码推断线上所有现象都由此造成，生产服务器与旧缓存未操作。

## 四项结果

1. **生命同步**：Game私有remainingLives作为唯一数据源，只读lives提供给HUD、结算与按钮。扣命钳制到0；完整update状态转换后统一同步onChange，移除帧末重复通知。运行回合标记只在真正发射时启用，全部球死亡只结算一次，通关优先。
2. **五命**：ArcadeRules.initialLives统一为5，初始化与主动重开共用配置。HUD根据配置生成5个爱心槽，失去的爱心变暗；数字与无障碍标签读取同一个Game.lives。仅缩小爱心字符和间距以适应原紧凑HUD，不新增面板。
3. **原关续玩**：丢命只调用resetRound，清理旧球、未拾取道具、强化与特效，生成1颗准备球；保留当前关卡、同一块网格、已消除状态、积分与当前关卡参数。中央继续挑战直接start。下一关保留生命与总分，重新开始/失败重试才回第一关5命0分。0命禁止继续。
4. **掉落减半**：ArcadeRules.powerUpDropMultiplier配置首关1、第二关及以后0.5；LevelManager选择倍率，Physics只把原14块固定间隔除以倍率，得到14或28。没有叠加概率减半。掉落种类仍交替三倍球/加宽，效果、5秒时长、最多100球及24掉落槽均不变。

普通丢命不重置本关累计消除数，因此保留不足一个掉落间隔的进度；新关方块归零，不会继承旧关计数。已经销毁的格子不会再次触发掉落。

## 关键状态

| 事件 | 生命 | 关卡/方块/积分 | 状态与操作 |
|---|---|---|---|
| 新游戏 | 5 | 第1关/全量/0 | 开始游戏 |
| 第一轮全部漏掉 | 4 | 当前值保留 | 继续挑战，1颗准备球 |
| 下一轮全部漏掉 | 3 | 当前值保留 | 继续挑战 |
| 多球中仍有1颗存活 | 不变 | 继续运动 | 不扣命 |
| 通关下一关 | 继承 | 新网格/累计分数保留 | 中央下一关一次点击发射 |
| 最后1命全部漏掉 | 0 | 成绩保留至结算 | Game Over，禁止继续 |
| 主动重开/失败重试 | 5 | 第1关/全量/0 | 新局 |

死亡几何、窄出口、圆外框与160逻辑像素挡板间距完全沿用。唯一死亡条件仍为整球上缘严格越过y=1072，不按出圆或Canvas越界判死。

- `npm run typecheck`：通过。
- `npm test`：117项通过（保留100项，新增17项，多个验收场景在同一测试内连续验证）。
