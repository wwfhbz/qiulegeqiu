# 闯关规则 1.9（1.9.0-arcade-5l-12lv-fullskills-v7）

## 变化
| 项目 | 1.8（冻结） | 1.9 |
|---|---|---|
| 第1关 | 600块 | 不变 |
| 第2～12关砖区 | 球体上方80%（按砖数截取） | 整个球体到底线（`fullFloorGap=64`，与无尽模式相同） |
| 砖数（第2～12关） | 1200/1320/1500/1700/1800/2000/2100/2150/2400/2480/2560 | 1446/1634/1852/2139/2105/2518/2450/2444/2949/2928/2894 |
| 第2关预分配道具 | 12%，其中60%为×3（86/58） | 10%，其中60%为×3（87/58，数量不变） |
| 第3关掉落表 | ×3/加宽各50% | ×3 48.5%、加宽48.5%、闪电/穿透/火球各1% |
| 第4～12关掉落表 | ÷2 33%、×3 33%、加宽33.4%、生命/炸弹各0.3% | ÷2 32%、×3 32%、加宽32.4%、生命/炸弹各0.3%、闪电/穿透/火球各1% |

掉落间隔（第3关每14块→第12关每50块）、球速、出口、挡板、机关、生命、计分都不变。新道具效果与无尽模式相同：闪电击碎最靠下的12块，穿透4秒，火球6秒（中心+周围8格）。机关扫过的区域仍由砖块生成器空出。

## 验证
- 1.7/1.8 共用冻结的 `V17_LEVELS`，1.9 使用新的 `LEVELS`；服务端按挑战创建时的规则版本选关卡。
- 穿透/火球持续期间和闪电那一帧，"击碎四周无空隙的砖块"不计为可疑；每帧击碎预算按火球×9、闪电+12放宽。

## 发布
`deploy/leaderboard-contract.mjs` 已登记 1.8/1.7/1.6/1.5/1.3 → 1.9。`deploy/update.sh` 会先只装兼容后端（同时接受新旧规则），确认后再发布网页；微信小游戏在服务器更新后再上传。排行榜按模式永久统一，不清空。
