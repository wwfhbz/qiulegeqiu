# 《球了个球》经典街机规则 V0.6.1

## 一局与生命

一局初始 5 条生命，从第 1 关开始，累计分数为 0。准备状态下只有一颗球，玩家点击中央“开始游戏”发射。

- 多球中单颗球漏接，只回收该球，不扣生命。
- 运行状态下，全部球都漏接，扣 1 条生命。同一轮不会重复扣命。
- 扣命保留本关剩余方块、已消除数量和累计分数；清空掉落道具、加宽、粒子、连击与运动累计时间。
- 还有生命时，生成一颗准备球，等待玩家主动发射；不会自动发射。
- 生命为 0 时进入“游戏结束”。此时不能开始、继续或切到下一关，只能重新开始。
- 同一显示帧完成最后一个方块并丢失最后一个球时，优先结算通关，不扣命，生命奖励按本帧原有生命计算。
- 重新开始重置为第 1 关、5 命、0 分、4203 方块和一颗球。静音偏好保留。

## 得分与连击

只有方块第一次成功销毁才计分。物理层先原子清除 Uint8Array 中的标记，再通知积分系统；积分系统另有本关格子标记，防止事件重复计分。得分为整数。

每块基础 10 分。连击窗口为 **1.2 秒的有效物理模拟时间**。每次新的有效击碎会刷新窗口，当前这一击已计入连击数，然后按下表计算该块得分。

| 当前连击数 | 倍率 | 当前方块得分 |
| --- | --- | --- |
| 1～4 | 1 | 10 |
| 5～9 | 1.5 | 15 |
| 10～19 | 2 | 20 |
| 20 及以上 | 3 | 30 |

示例：连续击碎前 5 块为 `10+10+10+10+15=55` 分。前 20 块共 345 分。超时后连击归零、倍率恢复 1，下一块重新记为第 1 击。

暂停、页面隐藏触发的自动暂停、等待发射和结算期间，不消耗连击或强化计时。固定步长为 1/120 秒，不使用显示帧数计时。超过 0.1 秒的显示帧采用既有模拟时间上限；长时间后台停顿不补算。

每关通关奖励为：

`本关奖励 = 1000 + 剩余生命 × 500`

奖励不乘连击倍率，只发放一次。通关结算展示本关方块分、通关奖励、生命奖励、本关总分和累计总分。第 3 关最终胜利和游戏结束界面突出显示累计总分。

## 三关与难度

| 关卡 | 名称 | 方块数 | 基础球速系数 | 发射基础球速 |
| --- | --- | --- | --- | --- |
| 1 | 核心初探 | 4203 | 1.0 | 440 逻辑像素/秒 |
| 2 | 加速突破 | 4203 | 1.1 | 484 逻辑像素/秒 |
| 3 | 最终核心 | 4203 | 1.2 | 528 逻辑像素/秒 |

第 1、2 关通过后停止物理，显示结算与“下一关”。点击后保留生命和累计分数，重建 4203 方块，清除旧球、道具、强化和连击，生成一颗新球并立即发射。直接再次点击下一关不会跳关。

第 3 关通过进入最终胜利，不提供第 4 关或继续发射，仍可重新开始一局。关卡参数集中在 ArcadeRules.ts；增加后续关卡可扩展该配置，完成条件由 LevelManager 判断。

基础速度和最低速度随关卡系数变化，所有球速继续被限制在物理引擎的硬上限 760 逻辑像素/秒以内。碰撞法线反射、速度保持、2 像素子步进和三次接触修正沿用原系统。

## 挡板、出口与道具

- Canvas 逻辑大小 800×1120；圆心 (400,492)、半径 360，圆底 y=852。
- 水平挡板中心 y=1018、厚 12、正常宽 112，因此圆底到挡板顶边 y=1012 的可见间距为 **160** 逻辑像素。
- 挡板浅蓝色，样式和发光不变，只沿水平方向移动，中心正常范围 x=96～704，加宽时按真实宽度收窄范围；不旋转、不沿圆周运动。
- 球通过底部出口后继续模拟。圆外球撞闭合圆弧的外侧时向外反弹；外部挡板接球后向出口反弹并保留撞击位置对角度的影响。
- 整球上边缘严格越过挡板下方漏球线 y=1072 才回收，经过出口、圆外框或挡板附近不提前扣命。
- 第1关每击碎14块、第2关及以后每28块交替掉落三倍球和加宽道具，道具可下落到圆外挡板位置。
- 三倍球以当前有效球数为基础生成两倍额外球，总数最多 100；球状态独立，死亡对象复用。
- 加宽为 1.8 倍、持续 5 秒，重复拾取刷新持续时间。扣命或切关时立即恢复正常宽度。
- 粒子池 384、闪光池 64、掉落槽位 24；音效使用原有 Web Audio 限频和最多 12 个声部策略。

## 状态与操作

| 状态 | 玩家操作 | 物理模拟 |
| --- | --- | --- |
| 等待发射 | 水平移动、开始、重开 | 球停在挡板上方，只平滑移动挡板 |
| 运行 | 移动、暂停、重开 | 固定步长运行 |
| 暂停 | 继续、重开 | 球、道具、连击、强化全部冻结 |
| 本关通关 | 下一关、重开 | 冻结，不接受发射 |
| 游戏结束 | 重开 | 冻结，不接受发射 |
| 最终胜利 | 重开 | 冻结，不接受发射 |

页面顶部仅小品牌和紧凑HUD（关卡、爱心、分数、剩余方块），下方为完整Canvas与外部挡板。中央独立DOM层显示开始/继续挑战/恢复/下一关/重试，运行时隐藏。底部仅暂停/继续和重新开始，静音位于小型反馈行。

百球压力测试默认隐藏。开发者在地址后加 `?debug=1` 可显示，点击会重新开始第 1 关并发射 100 球，重置生命和总分。此入口为诊断工具，不属于正常街机进度。

## 架构

| 模块 | 职责 |
| --- | --- |
| ArcadeRules.ts | 生命、积分、连击窗口、奖励与关卡配置 |
| ScoreSystem.ts | 本关幂等计分、倍率、固定时间连击、一次性结算 |
| LevelManager.ts | 当前关卡、关卡数量、是否末关与切换 |
| GameState.ts | 六种状态和中文标签 |
| Game.ts | 状态协调、生命、通关优先级、重开/切关、输入循环 |
| Physics.ts | 既有物理、对象池、道具；新增可保留方块的 resetRound 和物理步/销毁事件 |
| GameUI.ts | 中文 DOM 界面、按钮绑定、HUD 与结算展示 |
| Renderer.ts | 竞技场、球、挡板、方块缓存与特效绘制，未参与积分/生命判定 |
| main.ts | 载入样式并挂载游戏 |

运行类型检查、117项单元测试与生产构建，保留原有100项测试并新增17项五命/原关续玩/掉落平衡测试；生产包完成PC与手机浏览器回归。

浏览器包括正常消除计分、实际掉落拾取、生命消耗、游戏结束发射限制、跨关生命与分数、最终胜利、暂停、静音、手机触摸、390/320 像素布局与 3 倍 DPR。完整三关结算场景通过真实 Blocks.hit 销毁事件快速构造，不宣称手工打完全部 12609 块；位移、漏接、按钮与正常击碎采用实际帧循环。

桌面和手机截图及原始报告在 docs/ 中。手机真机帧率、长时间游戏和音效听感仍需设备验收。本版本不含存档或排行榜；未修改生产服务器，合并 main 需要用户确认。

## V0.6.1 状态同步与平衡

Game内部只保存remainingLives，通过只读lives提供给HUD；同一轮最后一球死亡扣1命并钳制到0，update返回前同步通知完整状态。普通丢命不调用LevelManager.reset、Blocks.reset或ScoreSystem.reset。继续挑战复用当前网格与关卡；切关保留生命和总分，主动重开及失败后重试恢复第1关5命0分。

掉落倍率集中在ArcadeRules.powerUpDropMultiplier，LevelManager按关卡号选择1或0.5，Physics只将14块基数除以倍率得到14/28间隔。没有再叠加概率减半。使用本关累计已消除数，不另设跨关计数器；丢命保留触发进度，切关新网格归零。同格幂等销毁不重复掉落。
