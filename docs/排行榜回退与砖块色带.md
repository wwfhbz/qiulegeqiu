# 排行榜视觉回退与砖块色带

基线为 PR27 合并提交 `51eafcce070e1e71ab053674725ed4e75d9a575f`。旧版视觉来源是其合并前父提交 `7f8fc11abad5cc38e5da4bc79c62fba350161e34`。

## 修改范围

排行榜旧样式通过 `legacy.css` 仅限定于 `.ranking-dialog:not(.submission-view)`，恢复紫蓝主题、金色前五卡片、奖章、星芒、蓝色普通排名卡及紫色个人排名区域。保留 PR27 游戏主界面、成绩提交表单及游戏页奖杯图标。微信仅移植排行榜绘制、旧装饰素材和相应构建复制逻辑；保留错误换行、内容高度计算和滚动命中处理。

不回退排行榜接口与数据模型，不改变排名、身份、刷新、分页、历史或申诉行为。个人卡仍在弹窗内部，列表独立滚动；内容少时面板按内容收缩。装饰动画继续支持暂停、后台停止和低性能降级。

砖块通过共享 `brickColorIndex` 从稳定真实网格行号取得主色。每10行依次为海蓝、湖青、薄荷绿、琥珀黄、珊瑚橙、蓝紫；60行后循环。列号、种子和已消除数量不参与。保留原调色板索引，避免机关、道具颜色随顺序调整。Renderer原有圆角、高光、阴影、缓存与逐格清除不变。

各关使用自己的真实网格密度：第一关不会为了显示六色强塞60行。未新增特殊砖类型；当前普通砖一次命中消除，机关独立绘制，原状态标识和道具图标不变。
